# Скачивание книг с books.yandex.ru

Скрипты для сохранения книг из [books.yandex.ru](https://books.yandex.ru/) в PDF

## Установка

1) Python 3.8+ (подойдёт и новее).  
2) Зависимости:
```bash
python -m pip install -r requirements.txt
# или
py -m pip install -r requirements.txt
```
3) Браузер для Playwright:
```bash
python -m playwright install chromium
```

## Одиночное скачивание

```bash
python download_book.py <URL_книги> [имя_файла.pdf]
```
– открывается браузер, авторизуетесь (если нужно), книга сохраняется в `downloads`.

Что делает скрипт:
- подхватывает сохранённую сессию (`session_state.json`), чтобы не логиниться каждый раз;
- закрывает всплывашки (в т.ч. QR-предложение приложения);
- перед сохранением убирает панели ридера, заголовок и нижний прогресс — в PDF попадает только контент;
- сохраняет в горизонтальном A4 (две страницы на листе), скриншотом страницы браузера;
- пытается выставить прогресс на начало книги, чтобы идти с первой страницы;
- перелистывает по «стрелке» ридера (строго один шаг);
- останавливается, когда процент чтения из `data-e2e="footer.progress"` перестаёт меняться 5 раз подряд при значении > 85%;
- последняя страница сохраняется ровно один раз (дубли не пишутся);
- рядом с PDF кладёт `cover.jpg` — обложку книги.

## Пакетное скачивание по Excel

```bash
python batch_download_books.py books.xlsx
```
Формат листа (без заголовков):
- колонка A — номер (папка для книги в `downloads/<номер>`)
- колонка B — ссылка на книгу
- колонка C — название
- колонка D — автор (опционально)

Заметки по пакетному режиму:
- первый запуск — авторизуетесь в открывшемся окне, нажимаете Enter;  
  сессия сохранится в `session_state.json` и дальше подхватывается автоматически;
- если главная `books.yandex.ru` долго грузится, скрипт просит нажать Enter — можно продолжать вручную;
- после успешного скачивания каждая книга регистрируется в `downloads/COMPLETED.md` в формате:  
  `- <номер> — <название>`.

## Поведение и эвристики

- Прогресс берётся из `data-e2e="footer.progress"` (например, `35%`). Если футер недоступен — пробую вычислить % из `progress.slider input[type=range]`.
- Перед сохранением страницы больше не прокручиваю документ до конца (раньше из‑за этого прогресс прыгал почти к 99%). Лёгкий прокрут‑вверх остаётся только для «пробуждения» рендера.
- PDF формируется с параметрами:
  - формат `A4`, `landscape=True`, `scale=0.8`, поля `0`
  - фоновые элементы печатаются (`print_background=True`).
- Перелистывание строго по кнопке «вперёд» ридера (селектор семейства `Pagination_pagination_forward...`) с бэкапом на клик в правую зону.

## Где искать результаты

- PDF и `cover.jpg` — в `downloads/<номер_или_book_id>/`
- журнал завершённых книг — `downloads/COMPLETED.md`
- временные страницы хранятся в `downloads/<...>/temp_pages/` и после сборки удаляются.

## Частые вопросы

— «Просят капчу/логин»: решается вручную в открытом окне; сессия после этого сохраняется и дальше подхватывается.  
— «Полоса прогресса или шапка попали в PDF»: сейчас перед сохранением я их скрываю через CSS — в итоговый PDF они не должны попадать.  
— «Остановился слишком рано/поздно»: порог регулируется (сейчас > 85% и 5 одинаковых значений подряд). Если понадобится — скажите, вынесу в конфиг.
